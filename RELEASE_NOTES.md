# DotRec & DotRec Link — Релиз v1.0.0

🎉 Первый стабильный релиз бесплатного офлайн-рекордера экрана **DotRec (Android)** и десктоп-клиента **DotRec Link (Windows)**!

---

## 📱 DotRec (Android v1.0.0)

- **100% Офлайн и бесплатно**: без рекламы, без подписок, без водяных знаков. Приложение не запрашивает разрешение на доступ в интернет.
- **Интерфейс Nothing OS**: лаконичный монохромный стиль, фирменный точечный шрифт Doto, поддержка светлой и тёмной тем, тактильный отклик и плавная анимация кнопки записи.
- **Точки быстрого доступа**:
  - Плитка в шторке быстрых настроек с отображением хронометража.
  - Виджет 2×1 на рабочем столе.
  - Плавающая кнопка поверх экрана (с защитой `FLAG_SECURE` — не попадает на запись).
  - Ярлык приложения («App Shortcut») для мгновенного запуска.
- **Новые возможности записи**:
  - **Android 14/15**: поддержка захвата отдельного приложения или всего экрана.
  - **Режим «Игра»**: пресет 1080p·60 FPS, повышенный битрейт 20 Мбит/с, чистый звук игры.
  - **Звук**: раздельный или совместный захват микрофона и системного звука (`AudioPlaybackCapture`).
  - **Быстрая обрезка без перекодирования**: обрезка видео через прямой мультиплексор потока.
  - **Защита от сбоев**: восстановление и сохранение файлов при внезапном выключении или сбое.
  - **Диагностика**: экран «Проверка устройства» с замером характеристик дисплея, аппаратного HEVC/H.264 и оценкой размера файла на минуту записи.
- **7 языков**: Русский, English, Español, Deutsch, Français, Português, Українська.

## 💻 DotRec Link (Windows Desktop v1.0.0)

Десктоп-компаньон для трансляции экрана телефона на ПК и работы с OBS Studio.

- **Сверхнизкая задержка по USB**:
  - Автоматическая настройка проброса портов через `adb forward tcp:48211 tcp:48211`.
  - Сквозная задержка 28–42 мс (медиана **34 мс**) на 1080p·60 FPS без задержек mpv-буферов.
  - Альтернативное беспроводное подключение по Wi-Fi с безопасной привязкой по 6-значному PIN-коду.
- **Интеграция с OBS Studio**:
  - **В 1 клик через obs-websocket v5**: автоматическое добавление источника в активную сцену OBS.
  - **Browser Source с WebCodecs**: встроенный локальный сервер на `127.0.0.1:48212` с аппаратным ускорением в OBS.
  - **Window Capture**: безрамочный режим (F10) для чистого захвата окна в OBS без рамок Windows.
- **Локальная запись и скриншоты на ПК**:
  - Запись потока в MP4 в папку `Videos/DotRec` (`Ctrl + Shift + R`).
  - Сохранение снимков экрана в высоком разрешении (`Ctrl + Shift + S`).
- **Удобство использования**:
  - Сворачивание в системный трей при закрытии.
  - Горячие клавиши для всех ключевых действий.
  - Расширенные настройки сети, ADB и оверлея телеметрии (FPS, задержка мс, битрейт).
