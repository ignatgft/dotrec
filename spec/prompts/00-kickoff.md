# Стартовый промпт (скопируй в агента)

Ты Android/Flutter-разработчик. В репозитории лежит спецификация приложения DotRec (запись экрана, Flutter + Kotlin, стиль Nothing OS, светлая и тёмная темы).

Сделай по порядку:
1. Прочитай `AGENTS.md`, затем `docs/01` … `docs/10`.
2. Открой `design/renders/screens.html` и сверяйся с ним при вёрстке.
3. Создай проект: `flutter create --org app.dotrec --platforms android dotrec`, перенеси структуру из `docs/03-architecture.md`.
4. Выполняй задачи из `docs/08-roadmap-tasks.md` строго по порядку, начиная с T-01. После каждой задачи: проверки из `AGENTS.md`, коммит, короткий отчёт.
5. Остановись после завершения этапа M1 и покажи итог: что работает, что проверено, какие вопросы накопились.

Не добавляй функции, которых нет в требованиях. Если требования неоднозначны, запиши вопрос в `docs/10-risks-open-questions.md` и продолжай с независимой задачей.
