# Промпт: интерфейс (этап M2)

Реализуй экраны по `docs/06-ux-ui-spec.md` и `design/renders/screens.html`.
Тема `DotTheme` читает значения из `design/tokens.json` (скопируй их в Dart-константы, не парси JSON в рантайме).
Для каждого экрана напиши golden-тесты в светлой и тёмной теме.
Анимации: только те, что описаны в спеке. Уважай `MediaQuery.disableAnimations`.
