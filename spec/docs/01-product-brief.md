# 01. Продуктовый бриф

## Идея
Самый быстрый и красивый рекордер экрана для Android. Открыл, тапнул, пишешь. Минимум настроек, но те, что важны: разрешение, FPS, битрейт, звук.

## Для кого
- Обычные пользователи: записать игру, инструкцию, звонок в видеочате, баг для техподдержки.
- Энтузиасты: хотят контролировать FPS и качество без десятка скрытых меню.

## Почему не существующие рекордеры
- Встроенные рекордеры производителей: мало настроек, нет единого поведения между брендами.
- Магазинные приложения: реклама, водяные знаки, перегруженный интерфейс.
- DotRec: чистый интерфейс, нет рекламы и сети, прозрачные настройки.

## Принципы продукта
1. Запуск записи за 1 тап из трёх мест: приложение, шторка, виджет.
2. Умные пресеты («Быстро», «Баланс», «Качество»), детали спрятаны в настройках.
3. Один акцентный цвет (красный) только для записи.
4. Приложение офлайн и без аналитики.
5. Красота функциональна: точечный шрифт, большие тач-цели, чёткая иерархия.

## Не-цели (v1)
- Редактор видео, обрезка, наложение камеры, стриминг.
- Облачная синхронизация, аккаунты.
- iOS, desktop, web.
- Запись по расписанию, жесты «потряхивание» (кандидаты на v2).

## Метрики успеха (для себя)
- Старт записи после согласия: до 1 с.
- Падения записи: менее 0,5% сессий (по ручному тест-плану).
- Размер APK: до 25 МБ.
