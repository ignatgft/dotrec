# 10. Риски и открытые вопросы

Агент: сюда записывай вопросы и идеи вне спеки. Формат: дата, ID задачи, вопрос.

## Риски
| Риск | Влияние | Митигация |
|---|---|---|
| Производители убивают фоновый сервис (энергосбережение) | Запись обрывается | Foreground service с уведомлением; корректная финализация файла; подсказка про исключение из оптимизации батареи (только текст, без запроса разрешения) |
| Токен MediaProjection одноразовый (Android 14+) | Нельзя стартовать без диалога | Принять как ограничение, быстрый путь через `ConsentActivity`, не пытаться обходить |
| Звук системы блокируется приложениями | Видео без звука | Явное сообщение (FR-AUD-04) |
| `FLAG_SECURE` на оверлее работает не везде | Плашка попадает в запись | Проверка на матрице; плашка опциональна и выключена по умолчанию |
| Энкодер конкретного устройства не поддерживает параметры | Ошибка `prepare()` | Проверка `VideoCapabilities`, откат на ближайшие значения |
| 90/120 FPS на деле даёт меньше кадров | Ожидания не совпадают | Честная подпись: FPS записи ограничен частотой экрана и содержимым |
| MediaCodec-пайплайн сложнее MediaRecorder | Рассинхрон A/V | Вынесен в M4; MediaRecorder остаётся запасным путём |
| Лицензия шрифта | Юридический риск | Doto распространяется по OFL; сохранить файл лицензии в `assets/fonts/` и показать в «О приложении». Не использовать собственный шрифт Nothing (Ndot) |
| Стиль «как Nothing» | Товарный знак | Не использовать название и логотип Nothing в приложении; имя DotRec; только общий визуальный язык |

## Открытые вопросы (решить до релиза)
1. Показ касаний: делаем ли FR-SET-05 (нужен `adb`-грант) или убираем из v1?
2. Нужна ли запись с фронтальной камерой в углу (не в v1, но влияет на архитектуру пайплайна)?
3. Название и иконка: окончательные ли «DotRec» и точечный логотип?
4. Публикация: Google Play или только APK (влияет на требования к политике и фоновым сервисам)?
5. Нужны ли жесты для остановки (встряхивание)? Оценить после M3.

## Идеи на v2
- Запись по расписанию, встряхивание для остановки.
- Обрезка начала и конца записи.
- Режим «только игра» (запись одного приложения, Android 15).
- Фронтальная камера в углу.
- AV1, если аппаратный энкодер доступен.
