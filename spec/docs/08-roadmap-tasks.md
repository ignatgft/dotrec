- [x] **T-32 (A1). Протокол DotRec Link v1 и серверная часть на телефоне.** Реализация TCP-сервера `LinkServer.kt` (порт 48211), бинарный фрейминг `[type u8][flags u8][length u32][pts u64][payload]`, рукопожатие, 6-значный Wi-Fi PIN с TTL 2 мин, хук в `MediaCodec` для трансляции H.264 NAL, запуск согласия с ПК, экран телефона «Передача на ПК».
