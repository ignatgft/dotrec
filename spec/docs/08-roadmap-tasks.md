# 08. Этапы и задачи

Выполняй по порядку. Отмечай `[x]`. Одна задача = один коммит `T-XX: ...`.

## M0. Каркас

- [ ] **T-01. Создание проекта.** `flutter create --org app.dotrec --platforms android dotrec`. minSdk 29, targetSdk 35, Kotlin 2.x, структура папок по `03`. Включить строгий `analysis_options.yaml`.
  Приёмка: `flutter build apk --debug` собирается; `flutter analyze` чистый.
- [ ] **T-02. Тема.** `DotTheme.light/dark` из токенов, подключение шрифта Doto из assets, переключение Система/Светлая/Тёмная. Демо-экран с палитрой.
  Приёмка: golden-тест палитры в обеих темах.
- [ ] **T-03. Базовые виджеты.** `RecordButton` (все 6 состояний), `DotChip/DotSegmented`, `DotSwitch`, `DotCard`, `DotTimer`.
  Приёмка: widget-тесты на состояния; golden на обе темы; тач-цели ≥ 48 dp.
- [ ] **T-04. Локализация.** ARB `ru`, `en` со всеми ключами из `06`. Приёмка: нет хардкод-строк в виджетах (проверка поиском).

## M1. Нативное ядро (приоритет)

- [ ] **T-05. Контракт каналов и модели.** `reference/channel_contract.md` → Dart-модели и Kotlin-классы, сериализация, тесты. Приёмка: юнит-тесты сериализации на обеих сторонах.
- [ ] **T-06. Чистая логика.** `SizeCalc`, `BitrateCalc`, `FileNamer`, `DeviceCaps`-расчёты. Приёмка: юнит-тесты (≥ 15 кейсов: разные экраны, нечётные размеры, экран меньше целевого).
- [ ] **T-07. `RecorderStateStore` и `SettingsStore`.** StateFlow, SharedPreferences. Приёмка: юнит-тесты переходов состояний (все допустимые и запрещённые).
- [ ] **T-08. `ConsentActivity` + `RecorderService` (только видео).** MediaProjection, MediaRecorder, VirtualDisplay, foreground service, MediaStore. Требования FR-REC-01, 02, 03, 04, 08, NFR-REL-01, 03.
  Приёмка: ручной тест на устройстве: запись 30 с в 1080p·60 воспроизводится; файл лежит в `Movies/DotRec/`; на Android 14+ повторная запись снова просит согласие.
- [ ] **T-09. Остановка и очистка.** Чек-лист освобождения ресурсов, обработка `MediaProjection.Callback.onStop`, поворот экрана (resize). Приёмка: 20 циклов старт/стоп без утечек (проверка `adb shell dumpsys media.camera`/Profiler и отсутствием зависшего сервиса).
- [ ] **T-10. Пауза и продолжение, отсчёт 3-2-1.** FR-REC-06, 09. Приёмка: файл с паузой воспроизводится без разрыва звука/видео.
- [ ] **T-11. Уведомления.** Канал записи с хронометром и действиями, итоговое уведомление с «Открыть/Поделиться/Удалить». FR-ENT-04, FR-LIB-01.
- [ ] **T-12. Микрофон.** Запрос разрешения в момент включения, `setAudioSource(MIC)`. FR-AUD-01, FR-ONB-02/03.
- [ ] **T-13. Проверка места на диске.** NFR-REL-02.
- [ ] **T-14. Мост каналов.** `ChannelBridge`, EventChannel с отдачей текущего состояния при подписке. Приёмка: Flutter получает все состояния; повторное открытие приложения во время записи показывает верный статус.

**Контрольная точка M1:** остановись, сделай отчёт (что проверено на каких устройствах).
