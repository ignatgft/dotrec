# 06. UX/UI спецификация

Визуальные ориентиры: `design/renders/screens.html` (все экраны, светлая и тёмная темы) и `design/tokens.json`.

## Дизайн-идея
Чёрно-белый прибор с одной красной точкой. Всё нейтральное, красный появляется только там, где идёт или готовится запись. Точечный шрифт отвечает за «цифры и статусы», обычный шрифт за текст. Формы круглые, рамки тонкие (0,5 dp), теней нет.

## Токены
См. `design/tokens.json`.

| Токен | Тёмная | Светлая |
|---|---|---|
| bg | #000000 | #F1F1F1 |
| surface | #151515 | #FFFFFF |
| line | #2B2B2B | #DCDCDC |
| fg | #FFFFFF | #101010 |
| fgMuted | #8C8C8C | #6B6B6B |
| record | #D71921 | #D71921 |

Правила:
- Красный (`record`) только для индикаторов записи и кнопки записи. Не для ссылок, не для выбранных чипов, не для ошибок (ошибки текстом `fg` с иконкой).
- Выбранный чип: заливка `fg`, текст `onFg`.
- Никаких теней и градиентов. Глубина только рамкой 0,5 dp и сменой поверхности.
- Радиусы: чип 12, карточка 20, плитка 28, круг 999.

## Экраны

### 1. Онбординг (один экран)
- Сверху точечный логотип (три точки: серая, серая, красная).
- Заголовок (dot, 22): «Запись экрана без лишнего».
- Три строки с иконками: «Работает без интернета», «Нет рекламы и водяных знаков», «Файлы хранятся в Movies/DotRec».
- Кнопка «Начать» (заливка `fg`, 56 dp высота, ширина по контейнеру).

### 2. Главный экран
Сверху вниз:
1. Шапка: слева метка «REC» (dot, 12), справа иконки «Записи» и «Настройки» (24 dp, тач-цель 48).
2. Статус (dot, 44): `READY`, `00:42`, `PAUSED`, `SAVING`.
3. Подстатус (body, 13, fgMuted): «1080p · 60 FPS · 20 Мбит/с».
4. **Кнопка записи** 120 dp по центру (главный элемент экрана).
5. Подпись под кнопкой: «Начать запись» / «Остановить» / «Продолжить».
6. Блок «Пресет»: сегменты «Быстро · Баланс · Качество · Свой».
7. Блок «Разрешение»: `720 · 1080 · 1440` (недоступные приглушены).
8. Блок «FPS»: `30 · 60 · 90` (недоступные приглушены, под ними строка «Экран поддерживает до 60 Гц»).
9. Ряд круглых переключателей 48 dp: микрофон, звук системы. Включённый = заливка `fg`.

Поведение:
- Смена чипа переключает пресет на «Свой».
- Во время записи блоки 6–8 приглушены и не реагируют на нажатия, остальное работает.
- Пауза: вторая круглая кнопка слева от кнопки записи появляется только во время записи (48 dp, иконка паузы/воспроизведения).

### 3. Состояния кнопки записи
| Состояние | Вид | Анимация |
|---|---|---|
| Готов | Кольцо `fg` 2 dp, внутри красный круг 72 dp | нет |
| Отсчёт | Цифра 3-2-1 (dot, 44) в центре кольца, красного круга нет | цифра затухает 600 мс |
| Запись | Кольцо `fg`, внутри красный квадрат 44 dp, радиус 8 | морфинг 220 мс, пульс кольца раз в 2 с |
| Пауза | Кольцо `fg`, внутри красный круг 72 dp с иконкой паузы по центру `onFg` | нет |
| Сохранение | Кольцо превращается в точечный спиннер (8 точек по кругу) | вращение |
| Ошибка | Кольцо `fg`, внутри красный круг; под кнопкой строка причины | нет |

### 4. Настройки
Список групп с карточками `DotCard`:
- **Видео**: разрешение, FPS, битрейт (слайдер по значениям 4/8/12/20/40), кодек (H.264/HEVC).
- **Звук**: микрофон, звук системы.
- **Запись**: обратный отсчёт (Нет, 3 с, 5 с), плавающая плашка.
- **Вид**: тема (Система, Светлая, Тёмная), язык.
- **О приложении**: версия, «Работает офлайн», лицензии шрифта и пакетов.
Если параметры не поддерживаются устройством, строка приглушена, под ней причина (body, 12).

### 5. Записи
- Сетка 2 колонки: превью (формат 9:19,5), длительность (dot, 12) в углу, размер в подписи.
- Нажатие открывает системный плеер; долгое нажатие открывает меню «Поделиться», «Удалить».
- Пустое состояние: точечная иллюстрация пустой рамки, заголовок «Здесь появятся ваши записи», кнопка «Начать запись».

### 6. Плитка шторки
- Выкл: иконка видеокамеры, подпись «Запись».
- Вкл: красная точка, подпись с таймером (`00:42`), плитка в активном стиле системы.
- Нажатие: старт (с системным согласием) или стоп.

### 7. Виджет 2×1
- Слева круглая кнопка (кольцо + красный круг/квадрат), справа две строки: пресет (dot, 13) «1080·60» и подпись «Тап — запись» / «Идёт запись».
- Фон виджета `bg` темы, рамка 0,5 dp, радиус 22.

### 8. Плавающая плашка (опция)
- Пилюля: красная точка, таймер (dot, 13), кнопки пауза и стоп (24 dp иконки, тач-цель 48 dp).
- Перетаскивается, прилипает к краю, по умолчанию выключена.

### 9. Уведомления
- «Идёт запись»: хронометр, «Пауза», «Стоп». Малая иконка монохромная (кольцо с точкой).
- «Запись сохранена»: миниатюра, «Открыть», «Поделиться», «Удалить».

## Тексты (ru / en)
Правила: предложения с заглавной буквы, без точек на кнопках и заголовках, активный залог, без «пожалуйста» и «успешно».

| Ключ | ru | en |
|---|---|---|
| start | Начать запись | Start recording |
| stop | Остановить | Stop |
| pause | Пауза | Pause |
| resume | Продолжить | Resume |
| saved | Запись сохранена | Recording saved |
| open | Открыть | Open |
| share | Поделиться | Share |
| delete | Удалить | Delete |
| err_space | Мало места. Освободите хотя бы 200 МБ | Low storage. Free up at least 200 MB |
| err_consent | Запись не началась. Доступ к экрану не выдан | Recording didn't start. Screen access wasn't granted |
| err_mic | Нет доступа к микрофону. Откройте настройки приложения | No microphone access. Open app settings |
| fps_cap | Экран поддерживает до {n} Гц | Your screen supports up to {n} Hz |
| audio_blocked | Часть приложений запретила захват звука | Some apps blocked audio capture |
| empty_lib_title | Здесь появятся ваши записи | Your recordings will appear here |

## Доступность
- `Semantics` на кнопке записи: «Начать запись, кнопка» / «Остановить запись, идёт 42 секунды».
- Таймер объявляется TalkBack раз в 10 секунд, а не каждую секунду.
- Проверка масштаба шрифта 130%: чипы переносятся в две строки, а не обрезаются.
- Контраст `fgMuted` на `bg` не ниже 4,5:1 в обеих темах.
