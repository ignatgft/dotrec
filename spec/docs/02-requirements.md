# 02. Требования

Приоритеты: **P0** обязательно в v1, **P1** желательно в v1, **P2** после v1.
Каждое требование имеет ID. Задачи в `08` ссылаются на ID.

## Функциональные

### Запись (FR-REC)
| ID | Требование | P |
|---|---|---|
| FR-REC-01 | Запуск записи всего экрана через MediaProjection | P0 |
| FR-REC-02 | Выбор разрешения: 720p, 1080p, 1440p (нативное, если экран меньше, то недоступные пункты скрыты) | P0 |
| FR-REC-03 | Выбор FPS: 30, 60, 90 (пункты выше максимальной частоты экрана отключены с пояснением) | P0 |
| FR-REC-04 | Выбор битрейта: 4, 8, 12, 20, 40 Мбит/с, значение по умолчанию вычисляется из разрешения и FPS | P0 |
| FR-REC-05 | Выбор кодека: H.264 (по умолчанию), HEVC (если есть аппаратный энкодер) | P1 |
| FR-REC-06 | Пауза и продолжение записи (API 24+, доступно на всех minSdk 29) | P0 |
| FR-REC-07 | Остановка записи из уведомления, плитки, виджета, плашки и приложения | P0 |
| FR-REC-08 | Файл сохраняется в `Movies/DotRec/` через MediaStore, имя `DotRec_YYYYMMDD_HHmmss.mp4` | P0 |
| FR-REC-09 | Обратный отсчёт 3-2-1 перед стартом (можно выключить: «Нет», 3 с, 5 с) | P0 |
| FR-REC-10 | Ориентация: запись следует за ориентацией экрана, размеры видео пересчитываются при повороте | P1 |

### Звук (FR-AUD)
| ID | Требование | P |
|---|---|---|
| FR-AUD-01 | Микрофон вкл/выкл | P0 |
| FR-AUD-02 | Звук системы (AudioPlaybackCapture, Android 10+) вкл/выкл | P1 |
| FR-AUD-03 | Микс микрофона и звука системы в одну дорожку | P1 |
| FR-AUD-04 | Если приложение запретило захват звука, пользователь видит пояснение после записи, а не тишину без объяснений | P1 |

### Точки входа (FR-ENT)
| ID | Требование | P |
|---|---|---|
| FR-ENT-01 | Главный экран приложения с кнопкой записи и пресетами | P0 |
| FR-ENT-02 | Плитка в шторке: старт, стоп, таймер в подписи | P0 |
| FR-ENT-03 | Виджет 2×1: старт/стоп, текущий пресет | P0 |
| FR-ENT-04 | Уведомление записи: таймер, «Пауза», «Стоп» | P0 |
| FR-ENT-05 | Плавающая плашка с таймером, паузой и стопом (опционально, настройка выключена по умолчанию) | P1 |
| FR-ENT-06 | Виджет 1×1 (только кнопка) | P2 |

### Библиотека и результат (FR-LIB)
| ID | Требование | P |
|---|---|---|
| FR-LIB-01 | После остановки: уведомление «Запись сохранена» с действиями «Открыть», «Поделиться», «Удалить» | P0 |
| FR-LIB-02 | Экран «Записи»: список файлов DotRec с превью, длительностью, размером | P1 |
| FR-LIB-03 | Удаление записи с подтверждением | P1 |

### Настройки и тема (FR-SET)
| ID | Требование | P |
|---|---|---|
| FR-SET-01 | Светлая, тёмная, системная тема | P0 |
| FR-SET-02 | Пресеты «Быстро» (720p·30), «Баланс» (1080p·60), «Качество» (1440p·60 или максимум устройства) и «Свой» | P0 |
| FR-SET-03 | Все настройки сохраняются между запусками | P0 |
| FR-SET-04 | Язык: русский, английский (по системному) | P0 |
| FR-SET-05 | Показ касаний: экспериментальная функция, только если выдан `WRITE_SECURE_SETTINGS` через adb (см. `10`) | P2 |

### Онбординг и разрешения (FR-ONB)
| ID | Требование | P |
|---|---|---|
| FR-ONB-01 | Первый запуск: один экран с объяснением, что приложение офлайн и не собирает данные | P0 |
| FR-ONB-02 | Разрешения запрашиваются в момент нужды: уведомления при первой записи, микрофон при включении микрофона, overlay при включении плашки | P0 |
| FR-ONB-03 | При отказе в разрешении UI объясняет последствия и предлагает открыть системные настройки | P0 |

## Нефункциональные

### Производительность (NFR-PERF)
| ID | Требование |
|---|---|
| NFR-PERF-01 | От тапа до первого кадра в файле не более 1 с (после системного согласия) |
| NFR-PERF-02 | Пропуск кадров при записи 1080p·60 на устройстве среднего уровня менее 2% |
| NFR-PERF-03 | Нагрузка на CPU во время записи не выше 15% (энкодер аппаратный) |
| NFR-PERF-04 | Холодный старт приложения до интерактивного главного экрана не более 800 мс на устройстве среднего уровня |
| NFR-PERF-05 | Flutter-слой не участвует в обработке видео: ноль кадров через Dart |

### Надёжность (NFR-REL)
| ID | Требование |
|---|---|
| NFR-REL-01 | Если процесс сервиса убит, уже записанный файл остаётся воспроизводимым (фрагментированный MP4 или корректная финализация при `onDestroy`) |
| NFR-REL-02 | При нехватке места (менее 200 МБ) запись не стартует, пользователь видит причину; во время записи при критически малом месте запись останавливается и сохраняется |
| NFR-REL-03 | Любая ошибка кодека или проекции приводит к безопасной остановке и понятному сообщению |
| NFR-REL-04 | Состояние в UI, плитке, виджете и уведомлении всегда совпадает (единый `RecorderStateStore`) |

### Приватность и безопасность (NFR-PRIV)
| ID | Требование |
|---|---|
| NFR-PRIV-01 | Нет разрешения `INTERNET`, нет аналитики и крэш-репортеров в сети |
| NFR-PRIV-02 | Файлы только в публичной папке `Movies/DotRec/` через MediaStore, без широких прав на хранилище |
| NFR-PRIV-03 | Окна приложения (плашка) не попадают в запись (`FLAG_SECURE` там, где работает, проверка на устройствах) |

### UX и доступность (NFR-UX)
| ID | Требование |
|---|---|
| NFR-UX-01 | Тач-цели не менее 48 dp |
| NFR-UX-02 | Контраст текста не ниже WCAG AA в обеих темах |
| NFR-UX-03 | Поддержка TalkBack: у всех кнопок есть `Semantics` с понятными подписями |
| NFR-UX-04 | Поддержка системного масштаба шрифта до 130% без поломки макета |
| NFR-UX-05 | Анимации отключаются при `disableAnimations` |

### Совместимость (NFR-COMPAT)
| ID | Требование |
|---|---|
| NFR-COMPAT-01 | `minSdk 29` (Android 10), `targetSdk 35` |
| NFR-COMPAT-02 | Проверено на Android 11, 13, 14, 15 (см. `09`) |
| NFR-COMPAT-03 | Только портретная ориентация интерфейса приложения; запись следует за ориентацией экрана |
