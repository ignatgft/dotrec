# reference/

Заготовки, а не готовый код. Это стартовая точка и эталон формы.

- `channel_contract.md` — контракт каналов (обязателен к исполнению).
- `RecorderStateStore.kt` — единый источник правды о состоянии, с проверкой переходов.
- `RecorderService.skeleton.kt` — скелет сервиса; места `TODO(verify)` сверить с документацией Android.
- `BitrateCalc.kt` — расчёт битрейта по умолчанию (покрыть тестами).
- `recorder_state.dart` — Dart-модель состояния.
- `analysis_options.yaml` — строгий анализатор (положить в корень Flutter-проекта).
