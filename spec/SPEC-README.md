# DotRec — спецификация для агента

Рабочее название: **DotRec**. Приложение для записи экрана на Android.
Стек: **Flutter (Dart)** для интерфейса + **Kotlin** для нативного ядра записи.
Визуальный стиль: в духе Nothing OS (монохром, один красный акцент, точечный шрифт, круглые формы).
Темы: светлая и тёмная.

Главная цель: красиво, быстро, удобно. Минимум функций, максимум качества записи.

## Как пользоваться архивом

1. Прочитай `AGENTS.md`: правила работы, порядок действий, критерии готовности.
2. Прочитай документы по порядку (`docs/01` → `docs/11`). Каталог `11` это backlog, а не обязательные требования.
3. Открой `design/renders/screens.html` в браузере: все экраны в обеих темах.
4. Бери задачи из `docs/08-roadmap-tasks.md` строго по порядку. Одна задача = один коммит.
5. Стартовый промпт для запуска агента: `prompts/00-kickoff.md`.
