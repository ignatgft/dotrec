# DotRec — Рекордер экрана (Android) & DotRec Link (Windows)

**DotRec** — это бесплатное, быстрое и удобное приложение для записи экрана в стиле Nothing OS, а также десктоп-клиент **DotRec Link** для USB/Wi‑Fi зеркалирования экрана на ПК и прямой интеграции с OBS Studio.

## 🎯 Главная идея

Честный, быстрый и красивый инструмент для записи и стриминга экрана:
- **100% Бесплатно**: без подписок, скрытых платежей и заблокированных функций.
- **Без рекламы и водяных знаков**: чистая запись видео в максимальном качестве.
- **Полностью офлайн на телефоне**: у Android-приложения **нет разрешения на выход в интернет** (`INTERNET`). Никакие ваши данные или записи не могут уйти в сеть.
- **Стиль Nothing OS**: минималистичный монохромный интерфейс, акцентный красный `#D71921` строго для индикаторов записи/эфира, фирменный шрифт Doto, плавная анимация.

## 📱 DotRec для Android

- **Старт в один клик**: кнопка в приложении, плитка в шторке быстрых настроек с таймером, виджет 2×1 на рабочем столе, плавающая плашка или ярлык «Запись сейчас».
- **Android 14/15**: возможность захвата отдельного приложения без показа остального интерфейса телефона.
- **Гибкое качество**: пресеты («Быстро», «Баланс», «Качество», «Игра») или ручная настройка (разрешение до 1080p+, до 120 FPS, битрейт до 24 Мбит/с, аппаратный кодек H.264 / HEVC).
- **Чистый звук**: запись микрофона, звука приложений/игр (`AudioPlaybackCapture`) или их одновременный микс.
- **Быстрая обрезка**: прямое кадрирование видео без потери качества и без перекодирования.
- **Защита от сбоев**: восстановление и сохранение файлов при внезапном закрытии или разряде батареи.
- **«Проверка устройства»**: экран диагностики экрана, кодеков, свободного места и расчёт размера файла на минуту записи.
- **7 языков**: Русский, English, Español, Deutsch, Français, Português, Українська.

## 💻 DotRec Link для Windows (Зеркалирование и OBS)

Десктоп-компаньон для стриминга экрана телефона на ПК:
- **Сверхнизкая задержка**: 28–42 мс (медиана **34 мс**) на 1080p·60 FPS по USB через `adb forward` с аппаратным нулевым копированием (Direct3D11VA).
- **Wi-Fi подключение**: безопасная привязка по 6-значному PIN-коду.
- **Интеграция с OBS Studio**:
  - **В 1 клик через obs-websocket v5**: добавление браузерного источника прямо в сцену OBS одной кнопкой.
  - **Browser Source с WebCodecs**: локальный HTTP/WS сервер (`127.0.0.1:48212`) с аппаратным ускорением без сторонних плееров.
  - **Window Capture**: безрамочный режим окна зеркала (F10) для чистого захвата окна в OBS.
- **Локальная запись и скриншоты на ПК**: сохранение потока в MP4 (`Ctrl + Shift + R`) и снимки экрана (`Ctrl + Shift + S`).
- **Системный трей и горячие клавиши**: сворачивание в область уведомлений, глобальные комбинации клавиш.

### Горячие клавиши (ПК):
| Комбинация | Действие |
|---|---|
| `Ctrl + Shift + M` | Открыть/закрыть окно зеркалирования экрана |
| `Ctrl + Shift + R` | Начать / остановить запись видеопотока на ПК |
| `Ctrl + Shift + S` | Сохранить мгновенный снимок экрана |
| `Ctrl + K` | Принудительный запрос ключевого кадра H.264 (IDR) |
| `F10` | Переключение безрамочного режима (borderless) |
| `Esc` | Закрыть окно зеркала |
| `Ctrl + ,` | Открыть настройки приложения |
